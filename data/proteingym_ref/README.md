# ProteinGym reference data

Vendored from [OATML-Markslab/ProteinGym](https://github.com/OATML-Markslab/ProteinGym),
unmodified, so ProteinGym-derived scores here match the reference implementation
rather than a reimplementation of it.

`DMS_substitutions.csv` is the per-assay reference table (assay id, UniProt id,
sequence, MSA metadata), used by `proteingym_mlm_zeroshot.py`.

Cite: Notin et al., "ProteinGym: Large-Scale Benchmarks for Protein Fitness
Prediction and Design", NeurIPS 2023 Datasets and Benchmarks.
doi:10.1101/2023.12.07.570727
